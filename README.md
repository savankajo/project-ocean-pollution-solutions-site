# Ocean Pollution Solutions Site

A responsive educational website about ocean pollution, contamination, and practical ways to reduce environmental impact.

## What is included

- A full-screen visual hero about marine pollution
- Sections covering types of contamination, ecosystem impacts, and mitigation layers
- An interactive mitigation-strength planner
- Source links to UNEP, NOAA, and the National Park Service

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server.
